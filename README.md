\# 面试先锋 (Interview Pioneer)



面试先锋是一款 AI 驱动的沉浸式求职面试与复盘智能体。本项目专为缺乏真实求职经验的高校生打造，致力于提供懂岗位、会施压、能复盘的高阶 AI 面试教练服务。



\## 核心功能



1\. 简历深度解析与画像生成

支持上传文本型或图片型 PDF。内置轻量级 OCR 引擎（PyMuPDF 与 RapidOCR），结合大模型常识推理，可自动纠错 OCR 带来的错别字与水印干扰，精准提取求职者能力画像。



2\. 人岗匹配与定制化诊断

引入严格的评分标准（Rubric），依据简历与目标岗位输出结构化的匹配度得分、优势亮点与欠缺能力分析，并自动生成极具针对性的定制化面试题单。



3\. 沉浸式模拟面试

\- 提供 0-10 级面试官严厉度调节，支持从温和型 HR 到严厉型业务主管的人设动态切换。

\- 内置追问熔断机制，模拟真人面试官抓大放小的控场节奏，杜绝 AI 死磕单一问题。

\- 采用自然口语化对话，拒绝机械的系统提示词残留。



4\. 多维教练式复盘报告

面试结束后，导师 Agent 基于对话记录生成复盘报告。包含教练赋能评语与职场避坑指南，提供极具实操性的改进建议。



\## 技术栈



\- 前端框架：Streamlit

\- 大模型接口：DeepSeek API (兼容 OpenAI 格式)

\- 文档解析：PyMuPDF, RapidOCR

\- 数据与状态：Pandas, Streamlit Session State

\- 版本规范：SemVer (当前版本 v0.4.0)

\## 快速开始



1\. 配置 API Key

在项目根目录下新建名为 .env 的文件，填入你的 DeepSeek API Key：

DEEPSEEK\_API\_KEY="sk-你的真实API密钥"



2\. 运行项目



方式 A：一键启动（Windows 推荐）

直接双击运行项目根目录下的 启动.bat 文件。脚本会自动检测 Python 环境、创建虚拟环境、安装依赖并自动在浏览器中打开网页。



方式 B：开发者手动启动

uv run streamlit run app.py
